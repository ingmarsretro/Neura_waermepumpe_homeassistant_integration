# Security

Do not commit live host addresses, usernames, passwords or user salts.

In this repository the examples are:

- Home Assistant: `192.168.1.10`
- Heat pump: `192.168.1.100`
- Username: `kunde`

Replace them in your own Home Assistant config. Credentials belong in the integration setup dialog, not in Git.

---

Keine echten Adressen, Benutzer, Passwörter oder Salts ins Git legen.

Beispiele in diesem Paket:

- Home Assistant: `192.168.1.10`
- Wärmepumpe: `192.168.1.100`
- Benutzer: `kunde`

Zugangsdaten nur im Einrichtungsdialog von Home Assistant eintragen.
